SQL DATE & TIME FUNCTIONS:-------------------------CURDATE(): Current date.CURTIME(): Current time.NOW(): Current date and time.DATE(): Extract date part.TIME(): Extract time part.YEAR(): Extract year.MONTH(): Extract month.DAY()/DAYOFMONTH(): Extract day of the month.WEEK(): Extract week number.DAYOFWEEK(): Extract day of the week.DATE_ADD(): Add time to a date.DATE_SUB(): Subtract time from a date.DATEDIFF(): Difference between two dates.TIMESTAMPDIFF(): Difference between two DATETIME values.1. CURDATE() - Current DateDescription: Returns the current date in YYYY-MM-DD format (no time).SELECT CURDATE() AS current__date;Output:+-------------+| current_date|+-------------+| 2024-11-28  |+-------------+2. CURTIME() - Current TimeDescription: Returns the current time in HH:MM:SS format (no date).SELECT CURTIME() AS current_time;Output:+--------------+| current_time |+--------------+| 14:32:45     |+--------------+3. NOW() - Current Date and TimeDescription: Returns the current date and time in YYYY-MM-DD HH:MM:SS format.SELECT NOW() AS current_datetime;Output:+---------------------+| current_datetime    |+---------------------+| 2024-11-28 14:32:45 |+---------------------+4. DATE() - Extract Date PartDescription: Extracts the date part from a DATETIME or TIMESTAMP value.SELECT DATE('2024-11-28 14:32:45') AS extracted_date;Output:+----------------+| extracted_date |+----------------+| 2024-11-28     |+----------------+5. TIME() - Extract Time PartDescription: Extracts the time part from a DATETIME or TIMESTAMP value.SELECT TIME('2024-11-28 14:32:45') AS extracted_time;Output:+-----------------+| extracted_time  |+-----------------+| 14:32:45        |+-----------------+6. YEAR() - Extract YearDescription: Returns the year part from a DATE, DATETIME, or TIMESTAMP value.SELECT YEAR('2024-11-28') AS year_part;Output:+-----------+| year_part |+-----------+| 2024      |+-----------+7. MONTH() - Extract MonthDescription: Returns the month part (1–12) from a DATE, DATETIME, or TIMESTAMP value.SELECT MONTH('2024-11-28') AS month_part;Output:+------------+| month_part |+------------+| 11         |+------------+8. DAY() or DAYOFMONTH() - Extract Day of the MonthDescription: Returns the day of the month (1–31) from a DATE, DATETIME, or TIMESTAMP value.SELECT DAY('2024-11-28') AS day_part;Output:+-----------+| day_part  |+-----------+| 28        |+-----------+9. WEEK() - Extract Week NumberDescription: Returns the week number of the year (1–53) from a DATE, DATETIME, or TIMESTAMP value.SELECT WEEK('2024-11-28') AS week_number;Output:+--------------+| week_number  |+--------------+| 48           |+--------------+10. DAYOFWEEK() - Day of the WeekDescription: Returns the day of the week as an integer (1 for Sunday, 2 for Monday, ..., 7 for Saturday).SELECT DAYOFWEEK('2024-11-28') AS day_of_week;Output:+-------------+| day_of_week |+-------------+| 5           |+-------------+11. DATE_ADD() - Add Time to a DateDescription: Adds a specified time interval to a date or time.SELECT DATE_ADD('2024-11-28', INTERVAL 10 DAY) AS new_date;Output:diffCopy code+------------+| new_date   |+------------+| 2024-12-08 |+------------+12. DATE_SUB() - Subtract Time from a DateDescription: Subtracts a specified time interval from a date or time.SELECT DATE_SUB('2024-11-28', INTERVAL 10 DAY) AS new_date;Output:+------------+| new_date   |+------------+| 2024-11-18 |+------------+13. DATEDIFF() - Difference Between Two DatesDescription: Returns the number of days between two dates.SELECT DATEDIFF('2024-11-28', '2024-11-18') AS days_diff;Output:+-----------+| days_diff |+-----------+| 10        |+-----------+14. TIMESTAMPDIFF() - Difference Between Two Date/Time ValuesDescription: Returns the difference between two date or time values in the specified unit (e.g., seconds, minutes, hours, etc.).SELECT TIMESTAMPDIFF(DAY, '2024-11-18', '2024-11-28') AS days_difference;Output:+-------------------+| days_difference   |+-------------------+| 10                |+-------------------+15. STR_TO_DATE() - Convert String to DateDescription: Converts a string to a DATE, DATETIME, or TIMESTAMP using a specified format.SELECT STR_TO_DATE('2024-11-28', '%Y-%m-%d') AS formatted_date;Output:+----------------+| formatted_date |+----------------+| 2024-11-28     |+----------------+16. DATE_FORMAT() - Format a DateDescription: Formats a DATE, DATETIME, or TIMESTAMP value into a string according to a specified format.SELECT DATE_FORMAT('2024-11-28', '%W, %M %d, %Y') AS formatted_date;Output:+------------------------+| formatted_date         |+------------------------+| Thursday, November 28, 2024 |+------------------------+17. FROM_UNIXTIME() - Convert Unix Timestamp to DateDescription: Converts a Unix timestamp to a DATETIME value.SELECT FROM_UNIXTIME(1609459200) AS datetime_value;Output:+---------------------+| datetime_value      |+---------------------+| 2021-01-01 00:00:00 |+---------------------+18. UNIX_TIMESTAMP() - Convert Date to Unix TimestampDescription: Converts a DATETIME or DATE value to a Unix timestamp.SELECT UNIX_TIMESTAMP('2024-11-28 14:32:45') AS unix_timestamp;Output:+------------------+| unix_timestamp  |+------------------+| 1638111165      |+------------------+—------------------------------------------------------------------------------------------------------------------------------19. LAST_DAY() – Last Day of the MonthDescription: Returns the last day of the month for a given date.SELECT LAST_DAY('2024-11-28') AS last_day_of_month;Output:+-------------------+| last_day_of_month |+-------------------+| 2024-11-30        |+-------------------+20. MAKEDATE() – Create a Date from Year and Day NumberDescription: Returns a date from a given year and day number (1–366).SELECT MAKEDATE(2024, 60) AS result_date;Output:+-------------+| result_date |+-------------+| 2024-02-29  |+-------------+21. MAKETIME() – Create Time from Hour, Minute, SecondDescription: Returns a time value from hour, minute, and second.SELECT MAKETIME(14, 30, 15) AS result_time;Output:+-------------+| result_time |+-------------+| 14:30:15    |+-------------+22. MONTHNAME() – Full Name of the MonthDescription: Returns the name of the month from a date.SELECT MONTHNAME('2024-11-28') AS month_name;Output:+-------------+| month_name  |+-------------+| November    |+-------------+23. DAYNAME() – Name of the DayDescription: Returns the name of the weekday.SELECT DAYNAME('2024-11-28') AS day_name;Output:+-----------+| day_name  |+-----------+| Thursday  |+-----------+24. QUARTER() – Quarter of the YearDescription: Returns the quarter (1 to 4) of the year for a date.SELECT QUARTER('2024-11-28') AS quarter_value;Output:+---------------+| quarter_value |+---------------+| 4             |+---------------+25. EXTRACT() – Extract Specific Part of DateDescription: Returns part of a date (e.g., YEAR, MONTH, DAY, etc.).SELECT EXTRACT(WEEK FROM '2024-11-28') AS week_value;Output:+-------------+| week_value  |+-------------+| 48          |+-------------+You can extract:YEARMONTHDAYWEEKHOURMINUTESECONDQUARTERetc.26. ADDDATE() – Same as DATE_ADD()Description: Synonym for DATE_ADD(). Adds days or intervals.SELECT ADDDATE('2024-11-28', INTERVAL 5 DAY) AS new_date;Output:+------------+| new_date   |+------------+| 2024-12-03 |+------------+27. SUBDATE() – Same as DATE_SUB()Description: Synonym for DATE_SUB(). Subtracts days or intervals.SELECT SUBDATE('2024-11-28', INTERVAL 5 DAY) AS new_date;Output:+------------+| new_date   |+------------+| 2024-11-23 |+------------+28. SEC_TO_TIME() – Convert Seconds to TimeDescription: Converts an integer number of seconds to HH:MM:SS format.SELECT SEC_TO_TIME(3661) AS time_value;Output:+-------------+| time_value  |+-------------+| 01:01:01    |+-------------+29. TIME_TO_SEC() – Convert Time to SecondsDescription: Converts a time value into seconds.SELECT TIME_TO_SEC('01:01:01') AS total_seconds;Output:+----------------+| total_seconds  |+----------------+| 3661           |+----------------+30. SYSDATE() – Current Date and Time (Execution Time)Description: Returns the exact time at the moment the query executes (unlike NOW() which may be cached).SELECT SYSDATE() AS system_time;Output:+---------------------+| system_time         |+---------------------+| 2024-11-28 14:35:50 |+---------------------+ Display employee names along with their birth month number.SELECT emp_name, MONTH(birth_date) AS birth_monthFROM employee_attendance;Q8.
